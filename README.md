# HTML Tasks

A collection of small HTML practice tasks. Each task is one `.html` file.

## Tasks

| No | Task | What it covers | File |
| -- | ---- | -------------- | ---- |
| 1 | Text Formatting | bold, italic, underline, sub, sup, mark, br, hr | `text-formatting.html` |
| 2 | Header | h1 to h6 headings and the `<header>` tag | `header.html` |
| 3 | List | ordered, unordered and nested lists | `list.html` |
| 4 | Tables | rows, columns, colspan, rowspan | `tables.html` |
| 5 | Forms | input, radio, checkbox, dropdown, button | `forms.html` |
| 6 | Multimedia | image, audio, video, iframe | `multimedia.html` |

(Change the file names if yours are different.)

## How to Run

1. Open the folder in VS Code.
2. Right-click a `.html` file and choose **Open with Live Server**.
3. Or double-click the file to open it in the browser.
